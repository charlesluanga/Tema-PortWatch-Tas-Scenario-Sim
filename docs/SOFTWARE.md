# Software info

| Component | Version guidance |
|-----------|------------------|
| Python | 3.12 recommended |
| NumPy | >= 1.26 |
| pandas | >= 2.1 |
| SciPy | >= 1.11 (`scipy.optimize.linprog`, `scipy.stats`) |
| matplotlib | >= 3.8 |
| pytest | >= 7.4 |

OS: developed on Windows; scripts use `pathlib` and should run on macOS/Linux.
